## Overview

Molequle is a **Customer Data & Experience Platform (CDXP)** designed to help businesses unify customer, company, and behavioral data into a single source of truth. The platform enables teams to analyze user activity, generate insights, and trigger personalized workflows across multiple channels.

I joined the project as a **Senior Frontend Engineer**, contributing to both the **core web application** and the **Chrome & Firefox browser extensions**. I worked closely with the client — a senior backend engineer — collaborating directly on architecture decisions, API design, and feature implementation.

The primary goal was to build a **high-performance, scalable frontend** capable of handling complex data structures, real-time interactions, and seamless integrations.

## Key Features

- **Scalable Web Application**: Built the main application using **Next.js 12**, focusing on performance, maintainability, and clean component architecture. Implemented complex dashboards, data tables, and entity views for people, companies, and activities.
- **Browser Extensions (Chrome & Firefox)**: Contributed to the development of browser extensions using **React, TypeScript, Tailwind CSS, and React Query**, enabling users to capture, view, and sync data directly from the browser into the Molequle platform.
- **Data-Driven UI & State Management**: Integrated API-driven interfaces with **React Query** to handle server state, caching, background updates, and optimistic UI patterns for a responsive user experience.
- **Design-to-Code Collaboration**: Translated high-fidelity designs into reusable, accessible UI components while ensuring consistency across the web app and extensions.
- **Direct Client Collaboration**: Worked directly with the backend engineer client to align frontend architecture with API capabilities, iterate quickly on features, and resolve edge cases efficiently.

## Technologies Used

- **Next.js 12**: Core framework for building the web application with SSR and optimized routing.
- **React & TypeScript**: For building robust, type-safe UI components.
- **Tailwind CSS**: Utility-first styling for rapid development and consistent design.
- **React Query**: Server-state management, caching, and API synchronization.
- **Chrome & Firefox Extension APIs**: For browser-level integrations and data capture.
- **REST APIs**: For communication with backend services and data pipelines.

## Challenges and Learnings

One of the main challenges was handling **large, dynamic datasets** while keeping the UI fast and intuitive. This required careful component optimization, efficient data fetching strategies, and thoughtful state management.

Another challenge was maintaining **feature parity and consistency** between the web application and browser extensions, while working within the constraints of different browser environments.

Collaborating directly with a senior backend engineer sharpened my ability to make **architecture-level decisions**, communicate trade-offs clearly, and deliver features end-to-end with minimal friction.

## Outcome

The result was a **production-ready CDXP platform** with a performant web application and fully integrated browser extensions. The solution enabled teams to centralize customer data, gain actionable insights, and interact with their users more effectively.

This project strengthened my experience in:

- building complex, data-intensive frontend systems
- working with modern React and Next.js architectures
- collaborating directly with stakeholders on real-world SaaS products

This project highlights my ability to lead frontend development, integrate complex data workflows, and deliver scalable solutions across both web applications and browser extensions.
